可以幫我用 HTML 製作一組單字卡，卡片正面顯示法文與其例句, 點擊文字可發音, 反面顯示中文與英文。
改 HTML 可採用下列資料結構, 使用者可點擊卡片上按鈕 tag 該卡片。應用程式可設定只顯示特定 tag 的卡片。

wd={ "fr":"法文", "ss":"例句", "en":"英文", "zh":"中文" ..., "tag":[... "標記"] }
db=[... wd]

class Word {
	constructor( {wd} )
	createCard() => 產生單字卡 element
	slip() => 卡片翻面
	speak() => 發音
	note(tag) => 標記tag至該單字片(新增 Tag 至 tag屬性的串列
	match(tag) => 比對該tag是否在 tag屬性串列中
}
