互動式報表 (Standard Reports)

  • 核心功能與目的
    • 探索式分析、多維度鑽取 (Drill-down) 與連動篩選。
  • 最佳使用場合
    • 投資組合分析、股市走勢探索、業務 KPI 看板。
  • 關鍵設定參數 / 技術點
    • 欄位參數 (Field Params)、DAX 度量值、視覺化書籤。
  • 常搭配的數據表格類型
    • 星狀架構 (Star Schema)：事實表 (Fact) + 維度表 (Dim)。

編頁報表 (Paginated Reports)

  • 核心功能與目的
    • 格式固定的「像素級」精準報表，適合長表格分頁列印。
  • 最佳使用場合
    • 金融對帳單、發票、詳細成交清單 (Transaction List)。
  • 關鍵設定參數 / 技術點
    • 報表參數 (@Param)、運算式 (Expressions)、頁首頁尾佈局。
  • 常搭配的數據表格類型
    • 扁平化交易表：單一資料集、大批量純文字記錄。

儀表板 (Dashboards)

  • 核心功能與目的
    • 跨報表的指標彙整，提供單一畫面的高階概況。
  • 最佳使用場合
    • 企業戰情室、多專案監控、多策略組合摘要。
  • 關鍵設定參數 / 技術點
    • 動態磚 (Tiles)、即時警示 (Alerts)、問與答 (Q&A)。
  • 常搭配的數據表格類型
    • 彙整型指標 (Metrics)：來自多個報表的視覺效果釘選。

即時串流報表 (Real-time Streaming)

  • 核心功能與目的
    • 低延遲顯示最新數據，通常不存儲於資料模型中。
  • 最佳使用場合
    • 虛擬貨幣即時行情、IoT 感測器監測 (如 Pico 傳回的數據)。
  • 關鍵設定參數 / 技術點
    • 串流資料集 (Streaming API)、推送視窗 (Push window)。
  • 常搭配的數據表格類型
    • 時間序列資料：只有最新的一筆或短暫窗格內的資料。

計量指標報表 (Metrics/Scorecards)

  • 核心功能與目的
    • 追蹤特定目標的完成進度與狀態 (如：已達成/有風險)。
  • 最佳使用場合
    • 智能投資報酬率達標追蹤、學習進度管理。
  • 關鍵設定參數 / 技術點
    • 目標值 (Targets)、臨界值 (Thresholds)、人工簽入。
  • 常搭配的數據表格類型
    • 績效數據表：包含目標值、實際值與時間維度的表格。

💻 互動式報表常用圖表比較表

折線圖 (Line Chart)

  • 核心用途
    • 趨勢分析。呈現數值隨時間變化的走勢。
  • 資料參數與設定
    • X 軸：時間序列
    • Y 軸：連續數值
  • 關鍵差異與優點
    • 擅長顯示週期性、季節性與長期趨勢。
  • 金融/統計應用範例
    • 股價走勢、淨值變化、移動平均線 (MA)。
  • [Reference]

群組/堆疊柱狀圖 (Bar/Column)

  • 核心用途
    • 類別比較。比較不同項目間的離散數值。
  • 資料參數與設定
    • 軸：類別資料
    • 值：聚合數值
    • 圖例：次分類
  • 關鍵差異與優點
    • 堆疊強調總量與組成；
    • 群組強調項目間的絕對值比較。
  • 金融/統計應用範例
    • 不同投資組合 (Portfolio) 的季度收益率對比。
  • [Reference]

散佈圖/泡泡圖 (Scatter/Bubble)

  • 核心用途
    • 相關性與分布。尋找兩變數間的關聯。
  • 資料參數與設定
    • X/Y 軸：數值指標
    • 大小：第三維度 (泡泡圖)
  • 關鍵差異與優點
    • 識別異常值 (Outliers)、集群 (Clusters) 與相關係數。
  • 金融/統計應用範例
    • 現代投資組合理論的風險 (波動率) vs. 報酬率分布圖。

瀑布圖 (Waterfall)

  • 核心用途
    • 變動因果分析。解釋起點到終點的增減過程。
  • 資料參數與設定
    • 類別：變動階段
    • Y 軸：正負增量值
  • 關鍵差異與優點
    • 自動計算累計總計，並以顏色區分增(綠)減(紅)。
  • 金融/統計應用範例
    • 盈餘分析 (P&L)：從毛利到淨利的各項支出拆解。

矩陣 (Matrix)

  • 核心用途
    • 多維彙總。類似 Excel 樞紐分析表，但具連動性。
  • 資料參數與設定
    • 列/欄：多層級類別
    • 值：聚合度量值
  • 關鍵差異與優點
    • 支援階層式鑽取，能同時看到總計與詳細拆解。
  • 金融/統計應用範例
    • 分地區、分產品線的年度業績交叉彙對表。

樹狀結構圖 (Treemap)

  • 核心用途
    • 佔比與層級。以面積大小呈現部分與整體的關係。
  • 資料參數與設定
    • 分組：層級類別
    • 值：正數數值
  • 關鍵差異與優點
    • 適合展示大量類別，一眼看出誰是「大頭」。
  • 金融/統計應用範例
    • S&P 500 各板塊市值佔比熱力圖。

KPI/儀表 (KPI/Gauge)

  • 核心用途
    • 目標達成率。快速檢視單一核心指標狀態。
  • 資料參數與設定
    • 指標值：實際數值

  • 關鍵差異與優點
    • 提供顏色警示 (如紅黃綠)，適合即時監控。
  • 金融/統計應用範例
    • 基金經理人的年度獲利目標達成進度。

💻 進階與 AI 驅動圖表

ArcGIS 地圖 (ArcGIS for Power BI)

  • 核心用途
    • 進階地理空間分析。結合 Esri 的地圖圖層進行深度地理資訊探討。
  • 資料參數與設定
    • 位置：經緯度或地址
    • 大小/顏色：度量值
    • 參考圖層：人口普查或地標數據
  • 關鍵差異與優點
    • 層次感與豐富度：支援熱力圖、行車時間範圍 (Drive-time) 分析，並可疊加官方人口統計背景資料。
  • 金融/統計應用範例
    • 銀行分行選址：結合地區所得水準與交通便利性，分析分行服務覆蓋範圍與潛在獲利。

Python / R 視覺化

  • 核心用途
    • 自定義深度統計。執行 Power BI 內建圖表做不到的繪圖。
  • 資料參數與設定
    • 值 (Values)：傳入 Python 的 DataFrame 欄位
  • 關鍵差異與優點
    • 無限擴展性：可調用 Scikit-learn, Seaborn 等，處理非線性模型視覺化。
  • 金融/統計應用範例
    • 資產配置優化：繪製「效率前緣 (Efficient Frontier)」與蒙地卡羅模擬分布。
  • [Reference]

分解樹狀結構 (Decomposition Tree)

  • 核心用途
    • 根因分析。將一個高階指標拆解到多個維度中。
  • 資料參數與設定
    • 分析 (Analyze)：度量值
    • 解釋依據 (Explain by)：多個維度欄位
  • 關鍵差異與優點
    • 動態路徑：使用者可自選拆解順序，或由 AI 找出最大/最小值的關鍵路徑。
  • 金融/統計應用範例
    • 損益拆解：分析為何本月淨利下降？（按部門 -> 按產品 -> 按成本項）。

關鍵影響因素 (Key Influencers)

  • 核心用途
    • 因素重要性分析。識別哪些變數最能影響目標值。
  • 資料參數與設定
    • 分析：感興趣的指標
    • 解釋依據：候選影響因子（類別或數值）
  • 關鍵差異與優點
    • 統計自動化：後端自動執行迴歸分析，找出具有統計顯著性的因子。
  • 金融/統計應用範例
    • 違約風險分析：找出影響「貸款違約」最關鍵的因子（如年資、負債比）。

緞帶圖表 (Ribbon Chart)

  • 核心用途
    • 排名變動分析。觀察類別在時間序列中的排名切換。
  • 資料參數與設定
    • X 軸：時間
    • Y 軸：數值
    • 圖例：類別
  • 關鍵差異與優點
    • 視覺直觀：除了數值，更強調「排名 (Rank)」的消長，帶狀越粗代表數值越大。
  • 金融/統計應用範例
    • 基金績效排名：觀察多檔基金在不同季度間的績效名次變動。
  • [Sample]
     [Reference]

漏斗圖 (Funnel Chart)

  • 核心用途
    • 階段轉換分析。追蹤一個線性流程中各階段的流失率與留存率。
  • 資料參數與設定
    • 類別 (Group)：流程階段（需按順序排列）
    • 值 (Values)：量化指標
  • 關鍵差異與優點
    • 視覺化瓶頸：一眼看出哪一個環節流失最多（漏斗最窄處），並自動計算與前一階段的百分比。
  • 金融/統計應用範例
    • 信貸審核流程：從「收件 -> 初審 -> 徵信 -> 核貸 -> 撥款」的轉化效率分析。
