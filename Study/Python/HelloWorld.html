♫ 資料與程序

輸入 程序 資料 輸出

程式流程

  • 碼頭: 輸出入裝置, 例如: 檔案, 網路, 鍵盤, 螢幕
  • 報關行: 驅動程式
  • 工廠: 程序(處理器)
  • 倉庫: 資料(記憶體)

終端機: 標準輸入 / 標準輸出

  • 終端機 (console):
    • 終端機
  • 標準輸入 (stdin):
    • 終端機的預設輸入 (檔案ID:0)
    • input()
  • 標準輸出 (stdout):
    • 終端機資料的預設輸出 (檔案ID:1)
    • print()
  • 標準錯誤 (stderr):
    • 終端機錯誤訊息的預設輸出 (檔案ID:2)
  • 程序 (process):
    • 程式運行的實體

測試程式

## 註解是給人看得，機器迴避

# name 是一個儲存字串的變數
# input() 顯示提示字串後傳回使用者經 stdin 輸入的字串
name = input('請問大名')

# 字串變數 name 前端加上 '你好!' 後存到 message 字串變數
message = '你好! '+name
# 將 message 字串變數的內容傳給 stdout
print(message)
