🛠️ 程式註解

  • 程式註解是一種在原始碼中插入的非執行性文字。
  • 主要特點是：
    • 不被編譯或執行： 當程式碼被編譯器或直譯器處理時，註解會被完全忽略。它們不會影響程式的實際運作或輸出結果。
    • 目的在於溝通： 註解是用來向人類讀者（包括未來的您自己、協作的同事，或任何需要維護此程式碼的人）解釋程式碼的功能、原理、目的或任何重要細節。
  • 程式註解是良好程式設計習慣的基石，它們提供了幾項關鍵的價值：
    • 解釋複雜邏輯： 說明一段難以理解或不尋常的演算法是如何運作的。
    • 說明程式意圖： 解釋為什麼要這樣寫，而不是解釋程式碼做了什麼。例如，解釋為什麼選擇這個特定的資料結構或解決方案。
    • 標記重要資訊： 提示需要注意的錯誤 (Bug)、未完成的待辦事項 (TODO)，或未來可能需要的改進 (FIXME)。
    • 產生文件： 某些語言（如 JavaDoc, Python Docstrings），特定格式的註解可用來自動生成專案的 API 文件。
    • 臨時禁用程式碼： 在測試或偵錯時，可以用註解快速將某段程式碼暫時排除在執行之外，而不必刪除它。

🛠️ 程式函數 (Function)

  • 函數（Function）可以想像成一個有特定任務的小型機器或配方。

  • 定義

    • 函數是組織程式碼的一種方式。
    • 它是一個被命名的、獨立的程式碼區塊，設計用於執行特定的任務或計算。

  • 目的

    • 重用性 (Reusability)：您可以寫一次程式碼，然後在程式的不同地方多次呼叫（執行）這個函數，避免重複撰寫相同的邏輯。
    • 模組化 (Modularity)：將大型程式拆分成許多小、專注的函數，使程式碼更容易理解、測試和維護。
    • 抽象化 (Abstraction)：使用者只需要知道函數的名稱和它做什麼（例如 calculate_area(length, width)），而不需要知道它是如何實現計算的內部細節。

  • 範例

    def calculate_sum(a, b): # 這是函數定義 (Function Definition) result = a + b return result total = calculate_sum(5, 3) # 這是函數呼叫 (Function Call)

📦 參數/引數 (Arguments)

  • 定義： 參數是在呼叫函數時，提供給函數的值。這些值在函數的內部會被當作區域變數來使用。
  • 用途： 如果函數需要某些特定的資料才能完成其工作，這些資料就必須以參數的形式傳遞。
  • 形參 (Parameter)：
    • 在函數定義中宣告的變數名稱
    • # 函數定義時的 (a, b) 稱為形參 (Parameters) def calculate_sum(a, b): result = a + b return result
  • 實參 (Argument)：
    • 在函數呼叫時傳入的實際值
    • # 函數呼叫時的 (5, 3) 稱為實參 (Arguments) total = calculate_sum(5, 3) # 這是函數呼叫 (Function Call)

回傳值 (Return Value)

  • 函數執行完畢後給出的輸出結果。
  • 定義： 回傳值是函數執行完其工作後，將結果傳遞回呼叫者（Calling Code）的一種機制。
  • 用途：
    • 如果函數的任務是計算或產生一個結果 (如計算總和、查詢資料庫、生成報表)，它會使用 return 關鍵字將這個結果送出。
    • 函數只能回傳一個值（雖然這個值可以是複雜的資料結構，如列表或物件）。
    • 有些函數執行動作（如印出訊息或儲存檔案），但沒有需要回傳的計算結果，這種函數可以不寫 return，或隱式回傳一個特殊的「空值」 (例如 Python 的 None 或 C/Java 的 void)。
  • 範例：
    def calculate_sum(a, b): result = a + b # 使用 return 關鍵字將計算結果 (result 的值 8) 傳回去 return result # 呼叫函數後，回傳值 8 會被賦予給變數 total total = calculate_sum(5, 3) # total 的值現在是 8 print(total) # 輸出 8

🐍 Python 函數參數的類型 (Parameters in Python)

  • Python 參數主要可以根據傳遞方式（位置或名稱）和數量（固定或可變）來區分。

  • 必填的位置參數 (Positional-or-Keyword)

    • 定義： 這些是函數定義中必須提供值的參數，如果呼叫時未提供，程式會拋出錯誤。
    • 傳遞方式： 您可以按順序傳遞值 (位置傳遞)，也可以使用名稱傳遞值 (關鍵字傳遞)。
    • def greet(name, message): print(f"Hello, {name}! {message}") # 兩種呼叫方式都有效 greet("Alice", "Good morning.") # 位置傳遞 (按順序) greet(message="How are you?", name="Bob") # 關鍵字傳遞 (按名稱)

  • 具有預設值的參數 (Default Arguments)

    • 定義： 在函數定義時，為參數提供一個預設值。
    • 特性：
      • 可選 (Optional)： 如果呼叫函數時沒有為此參數提供值，它將使用預設值。
      • 必須放在後面： 任何帶有預設值的參數必須定義在所有沒有預設值的參數之後。
    • def power(base, exponent=2): # exponent 有預設值 2 return base ** exponent result1 = power(3) # 呼叫時省略 exponent，使用預設值 2 (3**2 = 9) result2 = power(3, 4) # 呼叫時提供 exponent，覆蓋預設值 (3**4 = 81)

  • 位置參數集合 (*args)

    • 語法： 在參數名稱前加上單個星號 (*)。
    • 用途： 用來接收任意數量的、額外的、位置傳遞的參數。
    • 特性： 傳入的所有位置參數會被打包成一個元組 (Tuple)。
    • def print_all(*names): # names 是一個 tuple for name in names: print(name) print_all("A", "B", "C", "D") # 傳入了 4 個參數 # names 的值會是 ("A", "B", "C", "D")

  • 關鍵字參數集合 (**kwargs)

    • 語法： 在參數名稱前加上兩個星號 (**)。
    • 用途： 用來接收任意數量的、額外的、關鍵字傳遞的參數。
    • 特性： 傳入的所有關鍵字參數會被打包成一個字典 (Dictionary)。
    • def print_profile(name, **info): # info 是一個 dictionary print(f"Name: {name}") for key, value in info.items(): print(f"{key}: {value}") print_profile("Alice", age=30, city="Taipei") # info 的值會是 {'age': 30, 'city': 'Taipei'}

  • 僅限位置參數 (Positional-Only Parameters)

    • 語法： 在所有僅限位置參數之後加上一個斜線 (/)。
    • 限制： 斜線前的參數只能通過它們在順序中的位置來傳遞，不能使用名稱 (關鍵字) 來傳遞。
    • 用途： 主要用於 API 設計，強制使用者依賴位置，避免因參數名稱變更而破壞程式碼。
    • def combined(a, b, /, c, d): pass combined(1, 2, c=3, d=4) # 正確：a, b 必須是位置傳遞 # combined(a=1, b=2, c=3, d=4) # 錯誤：a, b 不能使用關鍵字傳遞

  • 僅限關鍵字參數 (Keyword-Only Parameters)

    • 語法： 在所有僅限關鍵字參數之前加上一個單星號 (*)。這個星號可以是單獨的，或者跟在 *args 參數之後。
    • 限制： 星號後的參數只能通過它們的名稱 (關鍵字) 來傳遞，不能通過位置來傳遞。
    • 用途： 確保程式碼的可讀性，特別是對於那些不常用或含義不明確的參數。
    • def configure(debug=False, *, verbose=False): print(f"Debug: {debug}, Verbose: {verbose}") configure(debug=True, verbose=True) # 正確：verbose 必須是關鍵字傳遞 # configure(True, True) # 錯誤：verbose 不能用位置傳遞

📋 總結：函數參數的完整順序

  • 在 Python 的函數定義中，所有類型的參數必須按照以下嚴格的順序出現：
    1. 僅限位置參數 (Positional-Only)
    2. 位置或關鍵字參數 (Positional-or-Keyword, 無預設值)
    3. 位置或關鍵字參數 (Positional-or-Keyword, 有預設值)
    4. 單星號分隔符 (*) 或 *args (用來標記後面的參數為僅限關鍵字)
    5. 僅限關鍵字參數 (Keyword-Only)
    6. 雙星號字典 (**kwargs)

💻 模組: random

  • 浮點數

    • random() → [0, 1)

      • 由 0 到 1 之間隨機取得一個浮點數

    • uniform(最小浮點數, 最大浮點數) → [最小浮點數,最大浮點數) 或 [最小浮點數,最大浮點數]

      • 在最小浮點數與最大浮點數間隨機取一個浮點數
      • # [a,b) 因浮點數計算後四捨五入的關係變成 [a,b] def my_uniform (a, b): return a + random() * (b - a)

  • 整數

    • randrange(整數開始, 整數結束, 整數變動量) → [整數開始,整數結束)

      • 由 range(整數開始,整數結束,整數變動量) 中隨機取一個
      • def my_randrange (start, stop): return int(start + random() * (stop - start))

    • randint(整數最小, 整數最大) → [整數最小,整數最大]

      • 隨機取得一個最小為整數最小，最大為整數最大的整數
      • def my_randint (a, b): return int(a + random() * (b - a + 1))

  • 串列

    • choice(串列)

      • 由字串中隨機取得一個字元
      • def my_choice (s) : return s[randrange(len(s))]

    • sample(串列,個數)

      • 由串列中隨機取得個數個字元

    • shuffle(串列) → 洗牌後的串列

      • 為串列洗牌

📅 模組: datetime

  • datetime

    • datetime.now()

      → datetime 物件
      • 取得當前的本地日期和時間。
      • dt = datetime.now() # ⇒ 2025-12-09 14:10:56.123456

    • datetime.strptime(日期字串, 格式字串)

      → datetime 物件
      • 將字串依指定格式解析成 datetime 物件。
      • dt = datetime.strptime("2025/12/09 14:10", "%Y/%m/%d %H:%M") # ⇒ 2025-12-09 14:10:00

    • (datatime 物件).strftime(格式字串)

      → 日期字串
      • 將 datetime 物件格式化為字串輸出。
      • dt = datetime(2025, 12, 9, 14, 10) dt.strftime("%Y年%m月%d日") # ⇒ 2025年12月09日

    • (datetime 物件).date()

      → date 物件
      • 從 datetime 物件中取出日期部分 (回傳 date 物件)。
      • dt = datetime.now() dt.date() # ⇒ 2025-12-09

    • (datetime 物件).time()

      → time 物件
      • 從 datetime 物件中取出時間部分 (回傳 time 物件)。
      • dt = datetime.now() dt.time() # ⇒ 14:10:56.123456

    • (datetime 物件).weekday()

      → [星期一:0,1,2,3,4,5,星期日:6]
      • 回傳星期幾，週一為 0，週日為 6。
      • dt = datetime(2025, 12, 9) (週二) dt.weekday() # ⇒ 1

    • (datetime 物件).isoweekday()

      → [星期一:1,2,3,4,5,6,星期日:7]
      • 回傳星期幾，週一為 1，週日為 7。
