運算式 Expression

  • 計算運算式 Arithmetic Expression
    • Purpose: Combines numbers and operations (+, -, *, /) to produce a single number.
    • Example: 10 + 2 evaluates to 12.
    • Core Rule: Follows the order of operations to resolve to a quantity.
  • 比較運算式 Comparison Expression
    • Purpose: Checks how two values or expressions relate to one another using relational operators like >, <, or =.
    • Example: 10 + 2 > 7 + 1 evaluates to true (or 1) because 12 is greater than 8.
    • Core Rule: Evaluates the left and right sides first, then outputs a logic state (true/false).
