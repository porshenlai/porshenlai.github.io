反覆 Repeat

  • 迴圈(Loop) 控制程式反覆執行一段程式碼
  • 每次的執行，內容要有所改變
  • 迴圈應設置停止反覆的終止條件
  • White 迴圈
    • 請同學參加證照考試 直到 考試通過為止
    • Please take the certification test until passing it.
    • while student.score <= 700 : student.exam()
      • 成積不到 700 分就要反覆執行迴圈。
      • student.score 的初始值要如何設定呢 ?
      • student.exam() 會更新 student.score 的數值。
  • For 迴圈
    • 名單中的同學 請 參加證照考試。
    • Student in the list, please take the certification test.
    • for student in list : student.exam()
      • student 被依序替換成每個名單中的同學。
      • student.exam() 參加考試，通不通過都無所謂。

Fibonanci 序列

def fib (Bound) : a,b = 0,1 print(f"{a} ",end='') while b < Bound : a,b = b,a+b print(f"{a} ",end='') print('')
  • 檢查新產生的數據是否超過目標邊界
  • 將 b 給到 a，b 更新為 a+b
  • 指定的動作都是發生在計算完成之後 (等式右側都計算完才會執行等號的指定)
