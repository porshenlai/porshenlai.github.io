不可變 vs 可變

  • 不可變:
    • a='Lai' # 記憶體 'L', 'a', 'i # 索引表 "a":0 b=a # 記憶體 'L', 'a', 'i', 'L', 'a', 'i' # 索引表 "a":0, "b":3 a='賴柏伸' # 記憶體 '賴', '柏', '伸', 'L', 'a', 'i' # 索引表 "a":0, "b":3 print(f"→ a:{a},b:{b}")
    • → a:賴柏伸,b:Lai
  • 可變:
    • a=['L','a','i'] # 記憶體 'L','a','i # 索引表 "a":0 b=a # 記憶體 'L','a','i' # 索引表 "a":0,"b":0 a[1]='賴' # 記憶體 'L', '賴', 'i' # 索引表 {"a":0,"b":0} print(f"→ a:{a},b:{b}")
    • → a:['L', '賴', 'i'],b:['L', '賴', 'i']

結構 Structure

  • 元祖 Tuple
    • 不可變
    • 成員: (值:任意型態資料)
    • 取值: (1,2,3)[0] → 1
    • 地址資料
      015← 15*256← 3938(3938,"Lai")
      198← 98
      276← ord("L") ← "L" ← "Lai"
      397← ord("a") ← "a"
      4105← ord("i") ← "i"
      50← 0
      ...
      ...
  • 串列 List
    • 可變
    • 成員: (值:任意型態資料)
    • 取值: [1,2,3][0] → 1
    • 更新: [1,2,3][0] = 4 → [4,2,3]
  • 字典 Dictionary
    • 可變
    • 成員: (鍵:任意型態資料, 值:任意型態資料)
    • 取值: {"a":1,"b":2}["a"] → 1
    • 更新: {"a":1,"b":2}["a"] = 3 → {"a":3,"b":2}
  • 集合 Set
    • 可變
    • 成員: (唯一存在值:任意型態資料)
    • 檢查: "a" in {"a","b","c"} → True
    • 增加: {"a","b","c"}.add("d") → {"a","b","c","d"}
    • 刪除: {"a","b","c"}.remove("a") → {"b","c"}
