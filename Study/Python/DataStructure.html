  • 串列 List
    • 可變
    • 成員: (值:任意型態資料)
    • 取值: [1,2,3][0] → 1
    • 更新: [1,2,3][0] = 4 → [4,2,3]
  • 字典 Dictionary
    • 可變
    • 成員: (鍵:任意型態資料, 值:任意型態資料)

  • 集合 Set
    • 可變
    • 成員: (唯一存在值:任意型態資料)

    • 增加: {"a","b","c"}.add("d") → {"a","b","c","d"}
    • 刪除: {"a","b","c"}.remove("a") → {"b","c"}

演算法: 搜尋

  • 循序搜尋 (Sequential Search)
    • 從資料結構的第一個元素開始，由前往後逐一比對目標值，直到找到或看完所有資料為止。
    • 前置條件：無（資料不需排序，任意結構皆可）。
    • 時間複雜度：
      • 最好情況：O(1)（第 1 個就是目標）
      • 最壞情況：O(n)（看到最後一個或找不到，n 為資料量）
      • 平均情況：O(n)
    • 優點：邏輯簡單、程式極好寫、不需要預先排序。
    • 缺點：資料量大時效率很差。
  • 二元搜尋 (Bineary Search)
    • 利用「分治法」，每次將搜尋範圍對半切（折半）。先看中間的元素：若目標比中間大，就丟掉左半邊，往右半邊找；若目標比中間小，就往左半邊找。
    • 前置條件：資料必須已經事先排序（由小到大或由大到小）。
    • 時間複雜度：
      • 最好情況：O(1)
      • 最壞情況：O(log n)（每次砍一半）
      • 平均情況：O(log n)
    • 優點：速度快（資料量從 100 萬筆縮小到大約 20 次就能找到）。
    • 缺點：強烈依賴已排序的陣列，若資料常有新增、刪除等動態異動，維護排序成本高。
  • 雜湊搜尋 (Hash Search)
    • 利用雜湊函數（Hash Function）將鍵值（Key）直接對應轉換成記憶體中的儲存位置（Index），直接「一步到位」抓出資料。
    • 前置條件：需要建立額外的 Hash Table（雜湊表），且需設計良好的雜湊函數來減少碰撞（Collision）。
    • 時間複雜度：
      • 理想／平均情況：O(1)（常數時間，極快）
      • 最壞情況：O(n)（當發生嚴重碰撞、全部擠在同一個位置時）
    • 優點：搜尋速度極快，幾乎是常數時間 O(1)。
    • 缺點：需要額外的記憶體空間來存放 Hash Table，且處理碰撞（Collision）問題較為複雜。

演算法: 排序

  • 氣泡排序 (Bubble Sort)
    • 兩兩比較，大數往後交換。從頭到尾檢查相鄰的兩個元素，如果順序錯了就交換。每一輪結束後，最大的那個數就會像氣泡一樣「浮」到最右邊。
    • 核心策略：暴力窮舉（Brute Force）
    • 時間複雜度：
      • 最好：O(n)（資料原本就已排序好，且程式有加入優化旗標）
      • 最壞：O(n²)（資料完全反向排序）
      • 平均：O(n²)
    • 空間複雜度：O(1)（原地排序，不需要額外記憶體）
    • 穩定性：穩定排序（相同數值的相對順序不會改變）
  • 快速排序 (Quick Sort)
    • 選一個基準點，大放右、小放左。隨機選定一個元素作為「基準值（Pivot）」，將小於基準的通通移到左邊，大於基準的移到右邊，接著將左右兩邊各自重複這個過程。
    • 核心策略：分治法 (Divide and Conquer)
    • 時間複雜度：
      • 最好：O(n log n)
      • 最壞：O(n²)（當每次選的基準點都是最大或最小值時，例如資料已排序好）
      • 平均：O(n log n)（實際執行速度通常是所有常規排序中最快的）
    • 空間複雜度：O(log n)（遞迴呼叫堆疊的深度）
    • 穩定性：不穩定排序
  • 合併排序 (Merge Sort)
    • 切到最小再合併，邊合併邊排序。將陣列不斷對半切開，直到每個子陣列都只剩一個元素（此時自然視為已排序）。接著兩兩「依序合併」並重新排序，像蓋房子一樣由下而上組回完整的排序陣列。
    • 核心策略：分治法 (Divide and Conquer)
    • 時間複雜度：O(n \log n)（不論資料長怎樣，分割與合併的步驟都是固定的）
    • 空間複雜度：O(n)（合併過程中需要額外的臨時陣列來存放資料）
    • 穩定性：穩定排序
