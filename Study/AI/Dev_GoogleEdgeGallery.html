Ollama

  • Run open models.
  • Get more usage.
  • Ollama lets you use open models with your coding agents so you can spend less while keeping your data private.
  1. Download from [ollama.com]
  2. Double click to install
  3. [Ctrl+R] powershell to run terminal
  4. ollama list to check installed model
  5. ollama run tinyllama to run tinyllama chat
