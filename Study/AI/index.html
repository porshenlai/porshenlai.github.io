智慧這個詞

  • 當副詞用
    • 智慧行為：基於智慧進行決策後的行為
  • 當形容詞
    • 智慧機械：能進行智慧行為的機械
  • 當名詞用
    • 智慧：揭露世界運行法則的因果，關聯與規則
    • 人工智慧：根據觀察資料，產生規則。跟據規則，產生決策。

哪些動詞需要智慧？

  • (根據樣本來產生智慧)
  • 決策 → YES/NO → 認知 → 分類
  • 評估 → 數值 → 預測
  • 歸納 → 整齊的資料 → 分群
  • 改寫 → 中文>英文 → 翻譯
  • 簡而言之 → 摘要
  • 詳細來說 → 生成 (根據智慧來產生樣本)
  • 分類預測分群生成
