主機與模型

  • 主機與模型

    • 主機（例如:Ollama）

      • 遊戲主機
      • 軟體程式/引擎
      • 以 Go 或 C++ 語言開發的真實應用程式（.exe）
      • 將 模型資料載入至記憶體，進行數學計算並管理網路應用程式界面
      • 執行引擎與網頁伺服器
      • LLM 模型的程式邏輯（演算法）幾乎一致
      • LLM 間差異幾乎都在權重與資料集
      • 主機是讓腦可以思考與講話的身體（引擎/程式）

    • 模型（例如:Gemma）

      • 遊戲碟片/ROM 資料
      • 訓練學得的權重資料
      • 包含數億個學習產生的數值（參數）
      • 屬於被動資料，不能自己執行
      • 包含浮點數值矩陣（權重參數）的二位元檔案
      • 兩億參數模型（:2b）包含約兩億個代表知識與語言式樣的數值
      • 沒有程式，邏輯，運行的程序。純粹的靜態資料。
      • 是腦與知識
  • 輸入 ollama run gemma2:2b 時，Ollama 執行下列步驟:
    1. 載入模型檔案: 自硬碟讀取 gemma2:2b 權重檔案並將其載入至電腦記憶體或 GPU 的顯卡記憶體。
    2. 進行數學計算: 運行 C++/CUDA 程式碼來與這些權重進行矩陣乘法。
    3. 提供使用界面: 提供終端機界面 (CLI) 與 本地 RESTful API (http://localhost:11434) 供外部程式(例如 LangChain) 或網頁與模型交談。

LangChain: 工作原理

  • 關係圖
    繪製示意圖

  • Model

    • 模型檔案(.gguf) 是一個包含神經網路權重的被動檔案。
    • 模型 不具有自我執行或回應網路請求的能力。

  • Ollama

    • Ollama 扮演引擎以及網頁伺服器的腳色。
    • Ollama 於背景運行一個監聽 11434 連接埠的 Restful API 服務。

  • LangChain

    • LangChain 使用 Python 與 Ollama 的 Restful API 服務通訊。

LangChain 程式範例

  • # Install required modules: # !pip install langchain-ollama langchain-core from langchain_ollama import OllamaLLM # 1. Connect LangChain to your local Ollama instance running Gemma # (Ollama defaults to http://localhost:11434) llm = OllamaLLM(model="gemma2:2b") # 2. Send a prompt to the local model prompt = "Please explain what an LLM is in 2 simple sentences in Traditional Chinese." response = llm.invoke(prompt) print(response)

💻 Ollama + Gemma 快速安裝與體驗

  • 下載並安裝 Ollama

    • 前往 Ollama 官方網站：https://ollama.com
    • 點擊 Download，選擇對應電腦的作業系統（Windows）並下載安裝包。
    • 執行安裝檔，一路點擊 Next / Install 完成安裝。
    • 安裝完成後，系統列（右下角）會出現一個小火車/小羊圖示，代表 Ollama 已在背景運行。

  • 尋找可使用的語言模型

  • 下載並執行輕量版 Gemma 模型

    • 開啟電腦的終端機：Windows： 按 Win + R，輸入 cmd 或 powershell 並按 Enter。
    • 在終端機中輸入以下指令並按 Enter： ollama run gemma2:2b

  • 開始與地端 Gemma 聊天！

    • 當畫面出現 >>> 符號時，代表模型已在地端電腦成功運行，同學們可以開始輸入文字與它對話。
      • 💬 建議同學們可以試試看以下對話：
        • 請用繁體中文介紹一下你自己。
        • 什麼是 Python 的迴圈？請用簡單的比喻解釋。
        • 請幫我寫一封感謝老師指導的 E-mail 草稿。
    • 🚪 如何退出對話？
      • 在 >>> 後輸入 /bye 並按 Enter，即可退出聊天模式。
    • Hint: Windows: C:\Users\<使用者名稱>\.ollama\models
    • 可在終端機輸入 ollama list，如果能列出已安裝的模型列表，代表服務運作正常。

💻 Ollama 大量安裝

  • 📦 Phase 1: Preparation on Teacher's PC (Do Once)
    1. Download the Ollama Installer:
      • Download OllamaSetup.exe (Windows) or Ollama-darwin.zip (Mac) from ollama.com.
    2. Download the Gemma Model:
      • Run the installer on the teacher's PC, then open Command Prompt / Terminal and run: ollama run gemma2:2b
      • Wait for the download to finish. Test a quick message to ensure it works, then exit with /bye.
    3. Copy the downloaded model files:
      • [Windows] C:\Users\<Your-Username>\.ollama\models
  • 💻 Phase 2: Student PC Installation (Takes ~1 Minute per PC)
    1. Install Ollama
      • Double-click OllamaSetup.exe from the shared network drive to install the software.
    2. Copy the Model Folder
      • Copy the pre-downloaded .ollama folder from the network drive and paste it into their own User folder: C:\Users\Users\.ollama\
      • (Make sure the folder structure ends up as .../.ollama/models/manifests/... and .../.ollama/models/blobs/...)
  • Step 3: Run Without Internet!
    • Open Command Prompt / Terminal and type: ollama run gemma2:2b
    • Because the model files are already in the .ollama folder, Ollama will launch INSTANTLY without downloading anything from the internet.
    • You can tell Ollama to load models from a secondary drive (e.g., D:\OllamaModels) using an Environment Variable:
      1. Copy the models folder to D:\OllamaModels.
      2. Set the Environment Variable in Windows:
        • Key: OLLAMA_MODELS
        • Value: D:\OllamaModels
      3. Now Ollama will read models directly from drive D:\ every time without needing re-downloads!
