雲端私有大語言模型服務

  • 大型全球生成服務供應商，在全世界租用或自建資料中來服務全球的使用者，收取服務費用 (Token計價)。
  • Anthropic ⇒ Claude
    • 最適合長文寫作、細膩邏輯推理以及程式開發。Claude 的文筆最接近真人，沒有生硬的「AI 味」，且非常擅長處理大型程式庫和複雜的長篇文件。
  • Open AI ⇒ Chat-GPT
    • 最適合做為全能型創意與多功能助理。它擁有最豐富的生態系統（GPTs 商店）、強大的語音模式，以及頂級的圖像生成（DALL-E 3）能力，泛用性最高。
  • Google ⇒ Gemini
    • 最適合即時網頁搜尋、超大文本處理與 Google 生態系整合。它能直接讀取您的 Gmail、Docs、Drive 等雲端檔案，且網頁資料更新速度極快，能生成附帶來源標籤的深度研究報告。

開源大語言模型

  • 平台: Hugging Face
  • 模型庫: Hugging Face/Models
  • 人工智慧雲端平台與生態系統
  • 提供 Repository 寄存服務，扮演模型集散中心(Central Hub)的角色
  • 做為服務端點，提供雲端推論應用程式界面
  • 可以將 Hugging Face 想成是 the GitHub + AWS for AI:
    • 雲端空間 (Hub): 它存放了 Google，Meta，Microsoft，以及社群研究者提供的數百萬個模型檔案，資料集，以及程式庫.
    • 雲端服務 (推論 APIs): 如果不想要在本地主機執行模型，Hugging Face 讓你可以透過 HTTP API 請求來使用在他們的雲端 CPU (依據 token 使用量或時間計費).

地端私有開源模型服務

  • 軟體工具
    • Ollama
      • 模型格式: GGUF
      • 模型庫: Ollama/Library
      • 工作平台: PC (Microsoft Windows, Linux, ...)
    • Google Edge Gallery
      • 模型格式: LiteRT
      • 模型庫: Hugging Face/LiteRT Community
      • 工作平台: Mobile (Android, iOS)
  • 本地應用程式
  • 本地引擎或執行裝置 (以 Ollama為例 )
    • 桌面應用: 安裝於本地電腦並管理本機 GPU/CPU 的硬體.
    • 離線運行: 下載源自 Hugging Face 的模型檔案到電腦的硬碟，所以可以 100% 離線運行.
    • 本地應用程式界面: Ollama 提供本機的網頁伺服器 (http://localhost:11434). 因此本地的 Python 腳本或 LangChain 的應用程式可以不必透過網際網路與模型溝通.
  • 自 HuggingFace 下載模型檔案 (.gguf) 供 Ollama 執行使用

主機與模型

    • 主機（例如:Ollama）

      • 遊戲主機
      • 軟體程式/引擎
      • 以 Go 或 C++ 語言開發的真實應用程式（.exe）
      • 將 模型資料載入至記憶體，進行數學計算並管理網路應用程式界面
      • 執行引擎與網頁伺服器
      • LLM 模型的程式邏輯（演算法）幾乎一致
      • LLM 間差異幾乎都在權重與資料集
      • 主機是讓腦可以思考與講話的身體（引擎/程式）

    • 模型（例如:Gemma）

      • 遊戲碟片/ROM 資料
      • 訓練學得的權重資料
      • 包含數億個學習產生的數值（參數）
      • 被動資料，不能自己執行。
      • 純靜態資料。無程式，邏輯，與運行程序。
      • 包含浮點數值矩陣（權重參數）的二位元檔案
      • 兩億參數模型（:2b）包含約兩億個代表知識與語言式樣的數值
      • 是腦與知識

  • 協同運行

    輸入 ollama run gemma2:2b 時，Ollama 執行下列步驟:
    1. 載入模型檔案: 自硬碟讀取 gemma2:2b 權重檔案並將其載入至電腦記憶體或 GPU 的顯卡記憶體。
    2. 進行數學計算: 運行 C++/CUDA 程式碼來與這些權重進行矩陣乘法。
    3. 提供使用界面: 提供終端機界面 (CLI) 與 本地 RESTful API (http://localhost:11434) 供外部程式(例如 LangChain) 或網頁與模型交談。

LangChain: 工作原理

  • LangChain
    Python 程式
    		 →(請求)→
    本地 Restful 伺服器
    :11434
    ↕ Ollama
    大語言模型
    推論引擎
    ←(回應)←
    LLM 模型檔案
    神經網路原始權重
    		 →(載入)→

  • Model

    • 模型檔案(.gguf) 是一個包含神經網路權重的被動檔案。
    • 模型 不具有自我執行或回應網路請求的能力。
    • 模型庫: hugging face
    • 模型庫: ollama

  • Ollama

    • Ollama 扮演引擎以及網頁伺服器的腳色。
    • Ollama 於背景運行一個監聽 11434 連接埠的 Restful API 服務。

  • LangChain

    • LangChain 使用 Python 與 Ollama 的 Restful API 服務通訊。

  • LangChain 程式範例

    • # Install required modules: # !pip install langchain-ollama langchain-core from langchain_ollama import OllamaLLM # 1. Connect LangChain to your local Ollama instance running Gemma # (Ollama defaults to http://localhost:11434) llm = OllamaLLM(model="gemma2:2b") # 2. Send a prompt to the local model prompt = "Please explain what an LLM is in 2 simple sentences in Traditional Chinese." response = llm.invoke(prompt) print(response)

💻 Ollama + Gemma 快速安裝與體驗

  • 使用 Powershell 命令下載並安裝

    • irm https://ollama.com/install.ps1 | iex
    • irm (Invoke-RestMethod): 自遠端伺服器網址抓取內容，資料或檔案。
    • iex (Invoke-Expression): 接受文字字串並立即在妳的電腦執行。

  • 下載並安裝 Ollama (Alternative)

    • 前往 Ollama 官方網站：https://ollama.com
    • 點擊 Download，選擇對應電腦的作業系統（Windows）並下載安裝包。
    • 執行安裝檔，一路點擊 Next / Install 完成安裝。
    • 安裝完成後，系統列（右下角）會出現一個小火車/小羊圖示，代表 Ollama 已在背景運行。

  • 尋找可使用的語言模型

  • 下載並執行輕量版 Gemma 模型

    • 開啟電腦的終端機：Windows： 按 Win + R，輸入 cmd 或 powershell 並按 Enter。
    • 在終端機中輸入以下指令並按 Enter： ollama run gemma2:2b

  • 開始與地端 Gemma 聊天！

    • 當畫面出現 >>> 符號時，代表模型已在地端電腦成功運行，同學們可以開始輸入文字與它對話。
      • 💬 建議同學們可以試試看以下對話：
        • 請用繁體中文介紹一下你自己。
        • 什麼是 Python 的迴圈？請用簡單的比喻解釋。
        • 請幫我寫一封感謝老師指導的 E-mail 草稿。
    • 🚪 如何退出對話？
      • 在 >>> 後輸入 /bye 並按 Enter，即可退出聊天模式。
    • Hint: Windows: C:\Users\<使用者名稱>\.ollama\models
    • 可在終端機輸入 ollama list，如果能列出已安裝的模型列表，代表服務運作正常。
