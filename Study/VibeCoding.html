Vibe Coding 是什麼 ?

Vibe Coding是什麼？矽谷最潮新名詞，會搶程式設計師工作嗎？

今天的一小時，我們要做什麼？

  • 認識什麼是 Vibe Coding（氛圍式程式設計）
  • 了解：為什麼商管背景也需要懂 Vibe Coding
  • 拆解 Vibe Coding 的基本流程與心態
  • 用 AI 做兩個前端小應用：
    • 範例 1：咖啡店簡單 Landing Page
    • 範例 2：營運 KPI Dashboard 小卡片
  • 最後：風險、限制與未來學習方向

什麼是 Vibe Coding？

  • 用自然語言（中文或英文）跟 AI 說明你想要的系統或頁面
  • AI 依照你的描述，自動產生可執行的程式碼
  • 你不一定要讀得懂程式碼，而是專注在：
    • 結果符不符合需求？
    • 操作體驗好不好？
    • 有沒有要再調整的地方？
  • 關鍵：你不是工程師，而是「會下指令的產品 / 商業策劃者」。

為什麼現在大家都在談 Vibe Coding？

  • LLM（大型語言模型）讓「用文字描述需求」就能產生程式碼變成可能
  • 2025 年「Vibe coding」被字典選為年度代表字，象徵 AI 參與開發已成主流
  • 科技公司、大型雲端平台紛紛推出 Vibe Coding 工具與服務
  • 重點不是「會不會寫程式」，而是「會不會跟 AI 合作做產品」。

為什麼商管背景也要學 Vibe Coding？

  • 快速做出「可以點來玩」的原型網頁，比 PPT 更有說服力
  • 行銷活動、問卷蒐集、報表儀表板，都可以自己先做 MVP
  • 跟工程師溝通時，可以用實際頁面示範，而不是只用文字形容
  • 未來職場：
    • 產品經理、營運分析、行銷企劃，都被期待會一點 AI + 原型製作
  • 你不一定要成為工程師，但能自己「把想法變成可以點的畫面」，很關鍵。

Vibe Coding 與傳統「學寫程式」的差別

  • 傳統：
    • 先學語法（HTML / CSS / JS…）
    • 自己慢慢敲每一行程式碼
    • Debug 可能佔掉大部分時間
  • Vibe Coding：
    • 先講清楚「你想做什麼」
    • AI 幫你產生一份可以執行的初版程式碼
    • 你透過「修改指令」一步步把結果修到可用
  • 對商管學生來說：這比較像「寫企劃書 + 指揮團隊」，而不是「自己寫程式細節」。

Vibe Coding 的基本流程（以前端網頁為例）

  • Step 1：描述需求
    • 「我要一個單頁網站，介紹 XX 產品，含標題、特色三點、行動呼籲按鈕。」
  • Step 2：AI 產生 HTML / CSS / JavaScript 程式碼
  • Step 3：你在瀏覽器打開，實際點一點、看感覺
  • Step 4：再用自然語言微調
    • 「把主色改成深藍」、「加上一個顧客推薦區塊」…
  • 重點不是一次講完所有細節，而是「先動手做，再慢慢修」。

範例一：咖啡店 Landing Page（示範用）

  • 情境：你要為一間「校園旁精品咖啡店」做一頁式網站
  • Vibe Coding 的指令範例：
    • 「幫我用 HTML + CSS 做一個咖啡店的單頁網站。」
    • 「畫面要有：標題區、三個產品特色、小小的菜單區塊、底部聯絡資訊。」
    • 「風格溫暖、淺棕色、適合手機瀏覽。」

範例一：AI 產生的 HTML（部分節錄）

  • Demo
  • 程式碼
<section class="hero">
  <h1>Campus Brew Café</h1>
  <p>一杯好咖啡，陪你度過每個專題夜晚。</p>
  <a href="#menu" class="btn">看菜單</a>
</section>

說明重點：你不需要自己手寫 <section>，但要會「看得出結構」，方便之後溝通修改。

範例二：營運 KPI Dashboard 卡片

  • 情境：你是營運 / 行銷人員，想快速做一個「本月數字看板」
  • Vibe Coding 指令示例：
    • 「幫我做一個商業儀表板風格的網頁。」
    • 「包含三個 KPI 卡片：本月營收、活躍用戶數、新客數。」
    • 「每張卡片顯示數字與上月比較的％變化，使用綠 / 紅顏色表示。」
  • 這種頁面很適合 demo「商業分析 + AI + 前端」的結合。

範例二：Dashboard HTML 結構示意

  • Demo
  • 程式碼
<div class="kpi-grid">
  <div class="kpi-card">
    <h3>本月營收</h3>
    <p class="kpi-value">$1,200,000</p>
    <p class="kpi-change positive">+12% vs. 上月</p>
  </div>
  <!-- 其他 KPI 卡片 -->
</div>

說明：同學將來可以把 Excel / BI 的數據接上這樣的前端畫面。

寫給 AI 的指令：幾個小技巧

  • 明確說出「用途」：
    • 例如「給大學生看的活動頁」、「給老闆看的管理儀表板」
  • 描述版面結構：
    • 有幾個區塊？每個區塊要放什麼？
  • 講清楚風格：
    • 顏色、感覺（專業、活潑、科技感…）
  • 從簡單開始，再一步步加功能，而不是一次要求太多
  • 把 AI 當作「前端設計實習生」，你是給 brief 的主管。

Vibe Coding 的限制與風險

  • AI 產生的程式碼不一定最有效率或最安全 :contentReference[oaicite:4]{index=4}
  • 如果完全不看程式碼，只看結果，可能埋下：
    • 錯誤邏輯、資料隱私問題
    • 未來維護困難（別人看不懂、自己也忘記）
  • 商業上要思考：
    • 這個原型是只給內部測試，還是要真正上線？
    • 什麼時候要請專業工程師重新實作？
  • 結論：Vibe Coding 很適合做原型與實驗，但正式系統要更謹慎。

課後可以怎麼持續練習？

  • 找一個自己有興趣的主題：
    • 個人品牌頁面、社團活動頁、投資紀錄 Dashboard…
  • 用今天的流程，再做 1～2 個小專案
  • 刻意練習：
    • 每次改 prompt 時，多說明一點「為什麼要這樣改」
    • 慢慢學會看懂常見的 HTML / CSS 結構
  • 若有興趣，可以再往：
    • 互動式 JavaScript、API 串接、資料視覺化 延伸
  • 目標不是變成工程師，而是成為「會用 AI 做數位產品」的商管人才。

總結：Vibe Coding 帶給商管人的 3 件事

  • 1️⃣ 你可以用自然語言，讓 AI 幫你完成前端原型
  • 2️⃣ 你可以用「可以點來玩」的網站溝通商業點子，而不是只有文字與簡報
  • 3️⃣ 你會開始用「指揮 AI 做事」的角度，重新思考自己在組織裡的角色
