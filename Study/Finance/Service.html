金融原理

  • 流動性管理

    • 金融機構為確保在特定時間內
      有足夠的現金或即時可用資金，來因應支付清算、客戶提領或市場交割需求，
      所進行的資金調度、排程與風險管控。

  • 支付清算機制

    • 指金融機構之間或客戶之間，
      因交易而產生的債權債務關係，
      透過特定系統進行傳遞、對帳、抵銷，並最終移轉資金
      完成結算流程的基礎設施。

嵌入式金融 與 開放銀行

  • 嵌入式金融 (Embedded Finance)

    • 指將金融服務（如支付、貸款、保險、分期）
      直接無縫整合進非金融產業（如電商、叫車平台、社群App、零工平台）的介面與流程中，
      核心在於「情境驅動與服務內嵌」。
    • 非金融業者（如蝦皮、Uber）如何透過 API 嵌入支付、理財與貸款功能。
    • 透過應用程式介面（API），將支付、借貸、保險或帳戶等金融服務直接融入自己的產品或服務平台中
    • 消費者在非金融品牌的日常消費情境中就能順便完成金融操作，不需要跳轉到其他銀行系統。

  • 開放銀行 (Open Banking) 與 API 金融

    • 指銀行透過應用程式介面（API），
      在取得客戶授權的前提下，
      將客戶的金融數據與服務安全地分享給第三方服務提供者（TSP業者），
      核心在於「數據共享與金融服務解構」。

銀行如何透過支付取得數據？

  • 自家發行的信用卡 / 簽帳卡

    • 如何取得： 當您刷該銀行的信用卡時，銀行底層就擁有您的消費紀錄。
    • 精細程度： 銀行知道商店名稱、消費金額、時間與產業別（Mcc Code，如餐飲、航空、百貨），但無法得知購物籃明細（例如知道您在量販店刷了2000元，但不知道您是買衛生紙還是高檔威士忌）。
    • 信用評比應用： 這是最傳統的內部信用評估（Internal Scoring）。穩定的刷卡與準時還款紀錄，是銀行認識您財務能力的第一步。

  • 銀行自營的電子支付 / 行動支付

    • 如何取得： 例如玉山銀行的「玉山Wallet」或透過銀行轉投資的電子支付工具。
    • 精細程度： 透過掃碼支付（如 TWQR 共通標準），銀行可以掌握更多微型商戶（如夜市、早餐店）的在地消費足跡。

  • 跨業生態圈合作（「嵌入式金融」的進階應用）

    • 如何取得： 銀行與非金融生態圈（如大型電商、叫車平台、外送平台）深度策略結盟，或者透過開放銀行（Open Banking）的架構，由消費者授權將支付數據共享給銀行。
    • 實際案例： LINE Bank（純網銀） 與其生態圈（LINE Pay、LINE 購物）的結合。當用戶在使用 LINE 支付展現出高度活躍且穩定的消費習慣時，即使該用戶是沒有傳統聯名信用卡的「信用小白（Credit Invisible）」，銀行也能評估其還款能力。

消費紀錄如何變成「信用評比」？

在金融科技中，這被稱為「另類數據（Alternative Data）徵信」。
AI 和大數據模型不會去管你買了什麼衣服，而是分析背後隱含的「行為特徵」
  • 消費穩定度： 每月固定有日常消費、定期定額支出、公用事業（水電費）代繳，代表生活型態規律。
  • 深夜或特定場所消費： 頻繁在深夜特定娛樂場所大額消費，模型可能會微調風險權重。
  • 通路分布： 如果消費多集中在高端零售或高頻次的生活必需品，與集中在當鋪、點數儲值相比，風險模型會給予截然不同的評分。
  • 支付工具黏著度： 願意長期綁定並高頻率使用某種支付，代表其數位足跡健全，欺詐風險（Fraud Risk）通常較低。

先買後付 (BNPL, Buy Now Pay Later)

  • 什麼是先買後付？
  • BNPL 到底是「支付」還是「放貸」？
  • BNPL 服務主要不是向消費者收利息，而是透過以下幾種核心方式來賺錢：
    • 向商家收取「交易手續費」（最主要的收入來源）
      • 運作方式： 當消費者在合作電商或實體店使用 BNPL 結帳時，BNPL 平台（或提供服務的金融機構/資融公司）會先全額撥款給商家，但會從中扣除一筆手續費。
      • 收費比例： 通常約占交易金額的 3%～9.5% 不等（台灣市場平均約 4%～5% 左右）。
      • 商家願意付錢的原因： 因為 BNPL 能降低消費門檻，吸引沒有信用卡或額度不足的年輕族群、學生與「無卡族」，大幅提高商家的成交率與客單價。
    • 消費者端的手續費、分期利息與設定費
      • 分期利息： 雖然短期（如 3～4 期）常見 0 利率，但若拉長分期期數（例如 6期、12期甚至36期），銀行或資融公司就會向消費者收取分期利息或分期手續費。
      • 帳戶管理費 / 平台服務費： 部分平台在核准額度或交易時，會向消費者收取一次性的手續費或服務費。
    • 逾期違約金與滯納金（高風險高收益）
      • 運作方式： 如果消費者沒有按時在期限內還款，平台會收取高額的滯納金、違約金或循環利息。
      • 潛在風險： 雖然這能帶來額外收入，但如果借款人違約率過高，這部分收入會被呆帳吃掉。
  • 透過 BNPL 累積大量年輕族群與無卡族的消費行為數據，銀行或金融集團可以用來進行精準行銷，未來進一步將這些用戶轉化為辦理信用卡、信貸、保險等其他高毛利金融商品的客戶。

客戶終身價值（CLV）與動態流失預測

  • 消金是典型的「薄利多銷/高頻交易」業務，獲客成本（CAC）極高，因此研究重點常放在「如何留住高價值客戶」。
  • 研究重點：
    • CLV (Customer Lifetime Value) 模型： 預測一個客戶未來 3-5 年能為銀行帶來多少手續費（刷卡手續費、跨行轉帳費、理財手續費）與利差貢獻。
    • 流失預預警（Early Churn Detection）： 客戶在徹底剪卡或銷戶前，通常會有「行為徵兆」（例如：月刷卡金額連續 3 個月下滑、提款頻率降低、App 登入次數減少）。
  • AI 發揮空間：
    • 利用時間序列與生存分析（Survival Analysis / XGBoost）模型，在客戶流失前 30 天自動觸發「個性化手續費折抵」或「精準權益推薦」，以最低成本挽回高價值客戶。

信用卡與支付手續費結構分析

  • 信用卡與電子支付的手續費（如手續費拆分 Interchange Fee、手續費率 1.5%~3%）是消金極大的手續費收入（Fee Income）來源，這背後有非常複雜的賽局與定價彈性。
  • 研究重點：
    • 價格彈性與回饋率的最佳化（Reward Rate Optimization）： 信用卡發卡行給「現金回饋 2% 或 3%」時，消費者的刷卡總額會增加多少？扣除回饋成本與清算手續費後，銀行的**淨手續費收益（Net Fee Income）**是否極大化？
    • 循環利息與手續費的平衡（Revolver Profile）： 研究哪些客戶會帶來手續費，哪些客戶會帶來循環利息，並分析其違約風險（連動到授信風控）。
  • AI 發揮空間：
    • 結合強化學習（Reinforcement Learning）或動態定價模型，針對不同客群動態給予「限時刷卡回饋/手續費減免」，達成刷卡量與手續費利潤的最佳平衡。

場景金融嵌入與交叉銷售

  • 消金手續費常常不是單獨存在的，而是透過「支付/轉帳」這個高頻入口，將客戶引導至「理財、信貸、保險」等高手續費商品的過程。
  • 研究重點：
    • 下一步最佳行動（Next-Best-Action, NBA / Recommendation Systems）： 分析客戶的交易明細（Transaction Line Items），預測他下一步最需要什麼金融產品。
    • 場景金融轉化率（Embedded Finance Conversion）： 例如，客戶在買機票（支付）時，推薦旅平險（保險手續費）；客戶帳戶餘額過高時，推薦貨幣基金（理財手續費）。
  • AI 發揮空間：
    • 利用自然語言處理（NLP）與圖神經網路（GNN）分析客戶的消費足跡（Merchant Category Codes, MCC），建構客戶的生活風格特徵（Lifestyle Profiling），精準推薦金融產品。

浮動資金與手續費的動態價值評估

  • 這是消金極度優秀但常被忽略的財務概念——「浮動資金（Float / 零息資金）」。
  • 研究重點：
    • 當客戶把錢放在電子支付帳戶（如 Line Pay / 街口）、信用卡未結算款項，或是活期存款帳戶中時，這些資金的利息幾乎為零。
    • 銀行或支付機構雖然只收取微薄的交易手續費，但掌控這些低成本浮動資金，拿去放款或買短票，能創造巨大的隱性利差收益。
  • AI 發揮空間：
    • 結合 ALM（資產負債管理）模型，預測消金用戶資金的「平均滯留時間（Duration）」與「提現/消費週期」，以極大化資金調撥效益。

嵌入式金融

  • Embedding Finance
  • 什麼是傳統銀行看（審）不到的數據？
    • 傳統銀行（特別是聯徵中心）的授信評估，看的是「財務三表」、「薪資轉帳證明」和「過去的信用卡還款紀錄」。
    • 痛點：這導致社會上有大量的「金融小白」（如：剛畢業的社會新鮮人、外送員、網拍團購主、夜市攤商、YouTuber），他們有賺錢能力，卻因為沒有傳統信用紀錄，被銀行拒貸。
    • 科技發想點：透過嵌入式金融，非金融平台可以提供哪些「替代性數據」來幫這些人建立信用畫像？
      • 電商/網拍平台：商家的退貨率、客戶好評率、庫存周轉速度、旺季營業額波動。
      • 外送/叫車平台（如 Uber/Foodpanda）：外送員的每日接單穩定度、準時送達率、客戶評分、上工時數。
    • 資訊科技如何實踐「小規模普惠放款」？
      • 「場景融資（Contextual Lending）」的科技解決方案。
      • 範例場景：網拍賣家的「閃電週轉金」情境：一位雙 11 期間需要進貨 50 萬元的蝦皮賣家，傳統上跟銀行申請貸款要跑 2 週，早就錯過商機。
      • 資訊科技的介入流程：API 自動串接：網際網路上的電商平台透過 API，在賣家授權下，直接將賣家過去一年的「銷售大數據」傳給合作網銀。
      • AI 機器學習風險模型：網銀的後台不用人工審核，而是用 AI 模型去跑賣家的營收數據，精算出「這家店未來三個月倒閉的機率是 0.5%」。
      • 自動化即時授信：系統在 10 秒內算好風險與利率（例如：議定 8% 利率），並在賣家的蝦皮後台介面跳出視窗：「您已通過 50 萬進貨額度，點擊一鍵撥款」。
      • 動態風險控制（最關鍵）：未來賣家每賣出一件商品，平台會自動扣除 5% 的營收直接還給銀行（動態還款）。
      • 這種靠科技「控制金流」的操作，比傳統要求房產抵押更安全。
