CLONE

  • 沒有子模組

    git clone (REPOSITORY)

  • 有子模組

    git clone --recurse-submodules (REPOSITORY)
    git clone (REPOSITORY) git submodule update --init --recursive git submodule sync --recursive
    git clone (REPOSITORY) git submodule update --remote --merge

PUSH

  • 有分支

    git submodule add -b (branch) (repository) (folder) git commit -m "Add submodule" git push

  • 沒有分支

    git submodule add git commit -m "Add submodule" git push

PULL

  • git config --global submodule.recurse true git pull
    git pull --recurse-submodules
