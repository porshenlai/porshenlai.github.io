殼層 SHELL

  • 供使用者操作系統的文字或圖形介面程式，負責解析指令並呼叫 OS API
  • command.com (MS-DOS)
  • powershell.exe (Windows)
  • explorer.exe (Windows 圖形化 Shell)
  • msys/mingw (Windows UNIX 模擬環境)
  • bash / zsh (Linux / macOS)
  • gnome-shell (Linux 圖形化 Shell)

標準輸入 (stdin)

  • 終端機接收資料的預設管道 (File Descriptor 檔案識別碼: 0)
  • 預設綁定設備：鍵盤
  • input()

標準輸出 (stdout)

  • 程式輸出正常結果的預設管道 (File Descriptor 檔案識別碼: 1)
  • 預設綁定設備：終端機螢幕
  • print()

標準錯誤 (stderr)

  • 程式輸出錯誤訊息或警告的專用管道 (File Descriptor 檔案識別碼: 2)
  • 獨立於 stdout，可將錯誤訊息與一般結果重導向至不同目標
  • print(file=sys.stderr)

程序 Process

  • 程序 (process): 正在記憶體中執行中的程式實體（包含指令碼、變數狀態、分配到的系統資源）
  • 例如︰ my_program.py (於 Python PVM 內執行的程序)

虛擬機 / 執行環境 Virtual Machine

  • 提供程式語言執行時（Runtime）的中介虛擬環境或 IDE
  • 例如︰ python3 (PVM), thonny, spyder, ...

終端機 Terminal (模擬器)

  • 負責提供字元輸入輸出視窗的軟體介面（將鍵盤輸入傳給 Shell，並把 Shell 輸出的字元繪製在螢幕上）
  • Command Prompt (cmd.exe)
  • Windows Terminal
  • LXQt QTerminal
  • PuTTY (SSH / 序列埠終端模擬器)

殼層 Shell

  • 命令列 Command Line 結構分解

      • Superuser Do：以超級使用者（系統管理員 root）權限執行後續命令

    • python3

      • Python Interpreter / Virtual Machine
      • 解析與執行 Python 位元碼 (Bytecode) 的平台

    • test.py 程式碼與參數傳遞

      import sys print(sys.argv)
      ↓
      ['test.py', '/dev/ttyS0', '115200']

虛擬化 Virtualization 與 Interpreter

  • 虛擬化 Virtualization
  • Bytecode 虛擬化技術（Bytecode Virtualization）：將原始程式碼編譯成中間碼（Bytecode），並透過虛擬機器（如 PVM）中的解釋器（Interpreter）逐條解釋執行的跨平台技術。
  • Interpreter（直譯器 / 口譯員）：邊翻譯邊執行的程式碼轉譯器。
  • Python Interpreter 實作與應用領域：
    • CPython：最標準的 Python 官方直譯器。
    • MicroPython：針對微控制器與嵌入式系統優化的精簡版 Python 直譯器。
  • Interactive Python Project: IPython (互動式命令列與 JRE 環境)
  • Web IDE: Google Colab (基於雲端 Jupyter Notebook 環境)
  • IDE: Thonny (專為初學者設計的 Python 開發環境)

關於 UNIX/Linux 與 Windows 在檔案目錄系統架構上的主要差異，下列何者描述正確？
UNIX 將所有硬體裝置與儲存區統一掛載於單一根目錄 `/` 下；Windows 則使用磁碟區代號（如 C:, D:）管理
Windows 將所有裝置視為檔案，UNIX 則使用代號（如 Drive A, B, C）管理
UNIX 系統中無法存取硬體設備，必須透過 Windows 模擬器
兩者皆無法建立虛擬或暫存的掛載點（Mount Points）
UNIX 系統中 `/dev/` 目錄的主要用途是什麼？
存放系統硬體裝置對應的虛擬檔案（如 Serial Port, 磁碟機等）
存放開發者編寫的 Python 原始碼
存放作業系統的核心編譯器 (Compiler)
存放使用者下載的桌面軟體安裝檔

關於 Python 的執行機制（Python Interpreter / PVM），下列何者說明正確？
Python 先將原始碼轉為 Bytecode（中間碼），再由直譯器（Interpreter）逐條轉譯執行
Python 是純編譯型語言，直接將原始碼轉為硬體機器碼 (.exe)
Python 不需要透過任何虛擬機環境，可以直接在 CPU 上執行
Python 只能在 Windows PowerShell 內執行，無法在 Linux 運行
當我們在 Linux 命令列執行 `PYTHONPATH=./ python3 main.py` 時，設定 `PYTHONPATH=./` 的目的為何？
告訴 Python 執行環境優先在當前目錄搜尋自訂的模組與封包
永久修改作業系統的系統全域環境變數
限制 Python 程式只能使用 1MB 的記憶體
將 `main.py` 自動備份到雲端資料庫
