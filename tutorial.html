排版 - 頁面切版

  • .fill to set a block maximized.
  • .col to enable the flex column, .col>.fill to set a variable size block.
  • .row to enable the flex row.
  • .row.zcs to set the block listed in a Z shaped path.
  • .row>.swd to set the width of children blocks according to the screen layout.

模板宣告

  • 建立 [data-template="模板名稱"] 節點來進行模板的宣告
  • 利用 [data-v="功能:資料名稱"] 來設定自動填入資料的方法與目標資料變數
  • 利用 [data-c="功能:資料名稱"] 來設定 DOM 自動建立邏輯與對應的目標資料變數

模板使用

  • 建立帶有資料的 textarea[data-xl="template:模板名稱"] 元件來自模板複製元件並填入資料。
