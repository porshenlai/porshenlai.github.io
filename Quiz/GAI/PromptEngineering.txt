下列何者最能正確說明何謂 Prompt？
x AI 的計算過程
x 用來訓練 AI 的參數集合
o 提供 AI 指令與溝通的文字語句
x 生成結果的圖像格式

Prompt 工程（Prompt Engineering）主要是指什麼？
x 編寫深度學習模型的架構程式碼
x 蒐集資料訓練 AI 模型
o 設計與優化給 AI 的提示語句
x 開發 AI 晶片的電路

Prompt 流程的第一步驟是什麼？
x 生成圖像
x 輸入 AI 系統
o 文字或詞句設計
x 檢查結果

關於優化 Prompt 的重要性，下列敘述何者正確？
x 任何 Prompt 都可以得到一樣的結果
x 愈長的 Prompt 就愈好
o 清晰具體的 Prompt 可以提升結果品質
x Prompt 僅適用於語音輸入

生成圖片時，下列哪一項不是好 Prompt 應具備的特點？
x 加入具體風格描述
x 涵蓋完整語境
o 簡單單字即可
x 明確表達主題

在文本生成中，Bad Prompt 容易產生什麼結果？
x 語意精確且連貫
o 語意模糊且錯誤
x 句子完整且引人入勝
x 有創意與感染力

Prompt 工程的核心能力不包括下列何者？
x 理解問題與需求
o 快速生成答案
x 提出方向性問題
x 掌握語言表達

x 生成更貼近預期的答案
