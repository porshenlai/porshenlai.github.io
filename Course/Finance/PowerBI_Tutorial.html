MS Excel vs. Power BI：數據分析定位差異

  • MS Excel：
    • 個人、單一檔案、靜態報表、試算表工具。
    • 異： 專注於單一檔案內的精確計算、複雜公式與小型數據集。操作直觀，適合個人分析與靜態報表。
  • Power BI：
    • 團隊、多數據源整合、動態互動式報表、BI 平台。
    • 同： 皆有強大的數據清理與分析能力 (例如：Power Query)。
    • 異： 專為處理大數據量、整合多種數據源、建立數據模型、動態互動式報表與共享協作而設計。
強調兩者關係是互補而非取代，定位在不同規模的數據任務。

工作單元對比：最小結構化單元

  • Excel： 儲存格 (Cell)。
    • 靈活性高，可輸入各種資料型態
    • 難以追蹤數據來源，常產生資料混亂
  • Power BI： 結構化資料 (Structured Data)。
    • 數據必須有定義良好的欄位 (Column) 與行 (Row)
    • 遵循資料庫設計原則，有利於大規模分析
Power BI 的數據處理是基於資料庫的思維。

數據組織對比：單位的集合

  • Excel： 工作表 (Sheet)。
    • 一組 Cell 的集合
    • 報表設計時，一個工作表往往就是一份最終報表
  • Power BI： 資料表 (Table)。
    • 從不同數據源匯入的實體，是數據模型的基本單位
    • 一個 Table 包含一類實體 (例如：客戶、產品、交易)
從「工作表」到「資料表」，思維從 2D 試算轉向 3D 數據模型。

數據清理與轉換引擎：Power Query

  • Power Query (M 語言)
    • Excel 和 Power BI 共享的 ETL (抽取/轉換/載入) 工具
    • 定位： 數據載入前的預處理階段
    • 用途： 數據清洗、合併、追加、轉換格式、逆透視等繁瑣任務，所有步驟都會記錄，可自動化重跑。
Power Query 是兩者的交集點，是學習 BI 的第一步。

M 語言 vs. Excel 公式 (Formula)

  • Excel 公式：
    • 如 SUM, VLOOKUP
    • 多數在 Cell 層級計算
    • (時機) 數據已經在 Sheet 中
  • M 語言 (Mashup Language)：
    • 專門用於 Power Query 處理步驟
    • 用於數據載入前的轉換邏輯
    • (時機) 數據從來源讀取時
M 語言是「數據準備」的邏輯，與 Excel 公式是「最終計算」的邏輯不同。

數據分析與建模語言：DAX

  • DAX (Data Analysis Expressions)：
    • Power BI 的專屬分析語言
    • (定位) 數據模型化與進階計算階段
    • (用途) 建立量值 (Measures)、計算欄 (Calculated Columns)，處理時間智慧、彙總、篩選等複雜分析
DAX 是 Power BI 的精髓，讓數據從報表變成商業洞察，是財金分析的強力工具。

程序自動化對比：VBA vs. Power Automate

  • VBA (Visual Basic for Applications)：
    • Excel 內的宏程式語言
    • (用途) 自動化 Cell 和物件操作，在桌面軟體環境內執行
  • Power Automate (Power BI Service)：
    • 微軟雲端自動化工具
    • (用途) 可排程或事件觸發 Power BI 數據刷新、報表通知等雲端服務流程
BI 平台的自動化通常是基於雲端服務的流程，而非桌面程式內的宏，更適合企業級流程。

Power BI 工作流程：三個核心階段

  1. 數據獲取/轉換 (Power Query/M 語言)
    • 連接數據源、清洗、轉換。
  2. 數據建模/分析 (DAX 語言)
    • 建立關聯、定義量值。
  3. 數據視覺化/共享 (Power BI Desktop & Service)
    • 設計報表、發布到雲端。
    4. Power BI 的分析步驟是一個有邏輯、可重現的過程。

Power BI Desktop：分析師的主要工具

  • 定位
    • 免費的桌面應用程式
    • 用於開發、設計報表與數據模型
  • 用途
    • 數據連線、清洗、DAX 編寫、視覺化設計
    • 儲存 `.pbix` 檔案
第一個要下載安裝的軟體，「免費」的。

Power BI Service：雲端共享與協作平台

  • 定位
    • 基於網頁的雲端服務 (需登入學校/公司帳號)
  • 用途
    • 發布、共享、管理報表與儀表板
    • 排程數據刷新
    • 團隊協作
區分 Desktop (設計端) 與 Service (發布端)。發布後才能讓他人透過網頁或手機 APP 檢視。

Power BI 帳號申請與登入

  • 必要條件
    • Power BI Service 服務需要使用 學校/公司信箱 (工作或學校帳號) 進行註冊
    • (注意) 個人 Gmail 或 Hotmail 通常無法直接註冊 Power BI Service
  • Desktop 登入
    • 軟體可離線使用，但發布報表到 Service 時需要登入此帳號
必須使用學校提供的 Email 註冊，才能登入 Service 並享有特定服務。

導覽頁面：Desktop 三大檢視區

  1. 報表檢視 (Report View)
    • 拖曳視覺效果，設計最終報表
  2. 數據檢視 (Data View)
    • 查看和篩選原始表格數據 (如 Excel 檢視)
  3. 模型檢視 (Model View)
    • 管理資料表之間的關聯，建立數據模型
Power BI 的設計是分層次的，三個檢視區各有專職。

測驗：數據分析建模的專用語言是什麼？

1. M 語言 (用於轉換)
2. DAX 語言 (用於建模)
3. VBA 語言 (用於自動化)
4. C++ 語言 (用於編譯)

測驗：Excel 與 Power BI 共用的 ETL 工具為何？

1. Power Query
2. DAX Engine
3. Power Automate
4. Cell Formula

測驗：Power BI Desktop 的哪種檢視用於管理表格間的關聯？

2. 數據檢視
3. 模型檢視
4. 視覺化檢視
