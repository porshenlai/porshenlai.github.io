    Console 模式概觀

    • 輸入：input(prompt) 讀取一行字串（含結尾換行去除）
    • 輸出：print(*values, sep=' ', end='\n') 將物件轉成字串後印出
    • 注意：input() 回傳一律是 str，需要自行轉型
    # 假設以終端機執行
name = input("請輸入姓名：")
age	= int(input("年齡："))	# 以 int 轉型
print(f"{name} 您好，今年 {age} 歲。")

    input() 與常見轉型

    # 讀取三種資料，並做適當轉型
from datetime import datetime
price = float(input("收盤價："))
shares = int(input("股數："))
trade_date = datetime.strptime(input("交易日(YYYY-MM-DD)："), "%Y-%m-%d")
print(price, shares, trade_date)
    • int(s)、float(s)：轉數值；bool(s) 以「是否為空字串」判斷 （bool("0") 仍為 True）
    • datetime.strptime(text, fmt)：字串→日期時間
    • 建議先 .strip() 去除空白，再轉型；必要時 try/except 防呆

    防呆：清理與例外處理

    try:
		txt = input("請輸入價格：").strip().replace(',', '')
		price = float(txt)
		print(f"價格為 {price:.2f}")
except ValueError:
		print("格式錯誤，請輸入數字。如：1234.56")

    三種格式化方式：總覽

    方法語法特色
    f"...{expr:spec}..." Python 3.6+，最直覺；可內嵌運算 (如 {x*1.05:.2f}) 可讀性佳、效能佳；推薦
    "...{0:spec}...".format(x) 較通用；可重複/具名參數 舊專案常見
    "...%f" % x C 風格；符號如 %d、%f 相容舊碼；不建議新碼首選

    格式規格字（Spec）常用表

    類別Spec/格式說明範例
    整數 d、b、o、x/X 十進位/二/八/十六進位 f"{255:d} {255:x}" → 255 ff
    浮點 f、e/E、g/G 小數/科學記號/自動 f"{3.14159:.2f}" → 3.14
    千分位 , 加千分位分隔 f"{1234567:,}" → 1,234,567
    寬度/對齊 {:<10}、{:^10}、{:>10} 左/置中/右對齊；可搭配填充字元如 {:_>10} f"|{42:<5}|{42:^5}|{42:>5}|"
    符號 +、-、 顯示正負號/只有負號/正留空白 f"{3:+d} {3:-d} {3: d}" → +3 3␠3
    百分比 % 乘以 100 並加 % 號 f"{0.0765:.2%}" → 7.65%
    repr !r 使用 repr(obj) 的顯示（含轉義） f"{"A\nB"!r}" → 'A\nB'

    f-strings 詳解

    x = 1234.5
print(f"市價：{x:,.2f}")
dt = datetime(2025, 10, 15, 9, 30)
print(f"時間：{dt:%Y-%m-%d %H:%M}")

    str.format() 與舊式 %

    # str.format
"市價：{0:,.2f} 股數：{1:d}".format(1234.5, 3000)
# % formatting
"市價：%,.2f 股數：%d" % (1234.5, 3000)

    str() vs repr()

    • str(obj)：給人看的「友善」字串
    • repr(obj)：給程式/除錯看的「精確」表示，常含引號、跳脫
    s = "Hello
World"
print(str(s))		# 兩行
print(repr(s))	 # 'Hello\nWorld'

    日期時間格式化常用表

    符號意義範例
    %Y四位數年份2025
    %m / %d月 / 日（零填充）10 / 05
    %H %M %S時 分 秒（24h）09 30 00
    %b / %B英文月縮寫 / 全名Oct / October
    %a / %A星期縮寫 / 全名Wed / Wednesday
    %z / %Z時區數值 / 名稱+0800 / CST
    ISOdt.isoformat()2025-10-15T09:30:00+08:00
     
    from datetime import datetime, timezone, timedelta
dt = datetime.now()
print(dt.strftime("%Y/%m/%d %H:%M"))
print(f"ISO: {dt.isoformat()}")

    金融情境範例 ① 報酬率報表

    from datetime import datetime
p0 = float(input("期初價："))
p1 = float(input("期末價："))
r = (p1 - p0) / p0
today = datetime.today()
print(f"日期：{today:%Y-%m-%d} 報酬率：{r:.2%}")

    金融情境範例 ② 簡易本息表

    P = float(input("貸款金額："))
i = float(input("月利率(%)："))/100
n = int(input("期數(月)："))
pmt = P * i / (1 - (1 + i) ** (-n))
print(f"本息均攤月付額：{pmt:,.0f}")
print("期數	利息		本金		餘額")
bal = P
for k in range(1, n+1):
		interest = bal * i
		principal = pmt - interest
		bal -= principal
		print(f"{k:>3d}	{interest:>8.0f}	{principal:>8.0f}	{bal:>10.0f}")

    常見錯誤與除錯

    • ValueError：輸入無法轉成指定型別 → 提示格式、加入 try/except
    • TypeError：None 或型別不符 → 在格式化前先 is None 檢查
    • 字串格式錯誤 → 善用 repr() 看見跳脫字元
    • 輸出對齊混亂 → 使用寬度與對齊規格（如 {:>10}）
