電腦視覺 (Computer Vision)

這是 TFJS 最豐富的領域，包含影像分類、物件偵測與人體特徵辨識。
  • MobileNet
    @tensorflow-models/mobilenet
    • 快速、輕量級的影像分類（可辨識 1000 種物體）。
  • COCO-SSD
    @tensorflow-models/coco-ssd
    • 物件偵測，能在單張影像中找出多個物體並標記位置。
  • PoseNet / MoveNet
    @tensorflow-models/pose-detection
    • 人體姿勢偵測，追蹤關節點（如手肘、膝蓋）。
  • Face Landmarks
    @tensorflow-models/face-landmarks-detection
    • 臉部特徵偵測，可辨識臉部 486 個 3D 座標點。
  • BlazeFace
    @tensorflow-models/blazeface
    • 超輕量級的臉部偵測（僅偵測邊框，不含特徵點）。
  • DeepLab
    @tensorflow-models/deeplab
    • 語義分割，將影像中的每個像素分配到特定的類別。

文字與自然語言處理 (NLP)

適用於情感分析、問答系統與文字處理。
  • Universal Sentence Encoder
    @tensorflow-models/universal-sentence-encoder
    • 將句子轉化為向量（Embeddings），用於語義相似度分析。
  • Toxicity
    @tensorflow-models/toxicity
    • 偵測文字內容是否包含冒犯性、威脅或髒話。
  • Question and Answer
    @tensorflow-models/qna
    • 問答系統，給予一段文章後，能回答相關問題（基於 BERT）。

音訊處理 (Audio)

  • Speech Commands
    @tensorflow-models/speech-commands
    • 語音指令辨識，可辨識簡單的單詞（如 Up, Down, Left, Right）。

如何在 Node.js 中安裝與使用？

要在 Node.js 中使用這些模型，你必須先安裝 TensorFlow.js 的 Node 加速版本（tfjs-node），然後再安裝特定的模型套件。
  1. 安裝指令
    # 安裝 TFJS Node 核心加速器 (使用 C++ 綁定)
npm install @tensorflow/tfjs-node
# 安裝你想使用的模型 (以 MobileNet 為例)
npm install @tensorflow-models/mobilenet
  2. 範例代碼 (影像分類)
    
const tf = require('@tensorflow/tfjs-node');

const mobilenet = require('@tensorflow-models/mobilenet');
const fs = require('fs');

async function run() {
	// 1. 載入模型
	const model = await mobilenet.load();

	// 2. 讀取本地圖片並解碼為 Tensor
	const imageBuffer = fs.readFileSync('image.jpg');
	const imageTensor = tf.node.decodeImage(imageBuffer);

	// 3. 進行預測
	const predictions = await model.classify(imageTensor);
	console.log('預測結果：', predictions);
}

run();

其他資源

除了上述 NPM 套件外，你還可以透過以下方式獲取更多模型：
  • TensorFlow Hub: tfhub.dev 有大量已轉換為 TFJS 格式的模型，可以透過 tf.loadGraphModel() 遠端或本地載入。
  • MediaPipe: 許多 MediaPipe 的先進模型（如手部追蹤、自拍分割）也已陸續與 TFJS 整合。
