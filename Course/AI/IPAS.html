L11101｜AI 的定義

從任務能力與技術路徑理解 AI

  • AI：讓機器執行需要「智慧」才能完成的任務（感知、推理、學習、互動）
  • 三層次：弱 AI（特定任務）、強 AI（通用）、超 AI（假想）
  • 三路徑：符號式（規則/邏輯）、資料驅動（機器學習/深度學習）、混合式（神經符號）

L11101｜AI 的主要分類（技術）

  • 規則式 AI：以知識工程與規則庫為核心，推論可解釋但維護成本高
  • 機器學習：由資料歸納規則，包含監督/非監督/強化學習
  • 深度學習：以多層神經網路處理高維資料（影像、語音、文本）

L11101｜AI 的主要分類（任務）

  • 感知：影像分類、物件偵測、語音辨識、NLP 分類/抽取
  • 決策：推薦、路徑規劃、資源分配、強化學習控制
  • 生成：文本、圖像、音樂、程式碼、3D/影片

L11101｜AI 應用光譜

  • 企業營運：客服自動化、流程機器人（RPA）
  • 行銷與推薦：個人化內容/產品排序
  • 金融：風險評分、詐欺偵測、量化交易輔助
  • 製造：預測性維護、瑕疵檢測、數位孿生
  • 醫療：影像輔診、病歷摘要、臨床決策支援

L11102｜AI 治理概念（總覽）

FATS 框架與風險分級思維

  • 原則：公平（Fairness）、問責（Accountability）、透明（Transparency）、安全（Safety）
  • 實務：資料治理、模型治理、部署與監控、事故回報
  • 法規趨勢：資料保護、AI 風險分級、模型與服務供應者責任

L11102｜AI 風險類型

  • 資料風險：偏見、洩漏、個資識別、授權不明
  • 模型風險：過擬合、漂移、魯棒性不足、可解釋性不足
  • 營運風險：供應鏈依賴、服務中斷、成本不可控
  • 倫理/社會：歧視、操弄資訊、生計影響

L11102｜治理作法與責任分工

  • 資料層：數據資產盤點、品質指標、匿名化/最小化蒐集
  • 模型層：開發卡點（設計審查）、測試與壓力測試、模型卡（Model Card）
  • 部署層：門檻控管（人機協作）、監控（漂移/濫用）、事件處理
  • 角色：資料擁有者、模型負責人、資訊安全、法遵、業務部門

L112 資料處理與分析概念

目標：從資料到洞見的端到端視角

  • L11201 資料基本概念與來源
  • L11202 資料整理與分析流程
  • L11203 資料隱私與安全

L11201｜資料型態與結構

  • 結構化（表格/欄位）：交易、感測、問卷
  • 半結構化（JSON/Log）：事件、API 回傳、系統記錄
  • 非結構化（圖像/語音/文本）：社群貼文、客服語音、醫學影像

L11201｜資料來源與取得

  • 內部系統：ERP/CRM/HR、資料倉儲/湖
  • 外部來源：開放資料、商業資料供應商、網路爬取（合規）
  • 即時流：IoT 裝置、點擊流、交易事件

L11202｜資料品質維度

  • 完整性（Completeness）與一致性（Consistency）
  • 準確性（Accuracy）與即時性（Timeliness）
  • 唯一性（Uniqueness）與可追溯性（Lineage）

L11202｜資料前處理步驟

  • 清理：缺失值處理、異常值偵測、去重與標準化
  • 轉換：編碼（One-hot、Label）、尺度調整、分箱
  • 特徵工程：聚合、交互特徵、降維（PCA）

L11202｜分析與建模流程（CRISP-DM）

  • 商業理解 → 資料理解 → 資料準備 → 建模 → 評估 → 部署
  • 每一步都需要與利害關係人對齊、產出可驗證的工件

L11202｜評估指標範例

  • 分類：Accuracy、Precision、Recall、F1、ROC-AUC
  • 回歸：MAE、RMSE、R²、MAPE
  • 排序/推薦：NDCG、MAP、Hit Rate、Coverage

L11203｜資料隱私與安全（總覽）

  • 個資分類：PII、敏感個資、去識別化資料
  • 保護技術：匿名化、假名化、差分隱私、聯邦學習
  • 存取控管：最小權限、審計追蹤、金鑰管理

L11203｜合規與倫理考量

  • 告知與同意、目的限定、資料最小化
  • 跨境傳輸與保存期限、第三方共享
  • 資料外洩應變與通報流程

L113 機器學習概念

目標：理解任務、學習范式與模型選型

  • L11301 機器學習基本原理
  • L11302 常見的機器學習模型

L11301｜ML 基本流程與心智圖

  • 定義問題類型（分類/回歸/聚類/序列/推薦/強化）
  • 選擇資料與特徵、拆分訓練/驗證/測試
  • 訓練 → 調參（Hyperparameter Tuning）→ 評估 → 部署

L11301｜監督式學習

  • 輸入 x → 標籤 y，學習 f(x) ≈ y
  • 常見任務：二元/多類分類、回歸、序列標注
  • 風險：資料偏誤、標記品質、分佈偏移

L11301｜非監督式學習

  • 無標籤資料中發現結構：聚類、降維、表示學習
  • 用途：顧客分群、異常偵測、視覺化、預處理

L11301｜強化學習（RL）

  • 智能體在環境中互動，透過獎勵最大化學習策略
  • 元素：狀態、動作、回饋、策略、價值函數
  • 應用：遊戲、機器人控制、資源調度

L11302｜常見模型地圖

  • 線性/邏輯式回歸、KNN、樹模型（決策樹/隨機森林/梯度提升）
  • SVM、Naive Bayes、K-Means、GMM
  • 神經網路（MLP/CNN/RNN/LSTM/Transformer）

L11302｜樹與集成方法

  • 決策樹：可解釋、易過擬合
  • 隨機森林：多樹投票，穩健與泛化較佳
  • 梯度提升（XGBoost/LightGBM/CatBoost）：業界常用、表現強

L11302｜神經網路要點

  • 表示學習：自動從資料中學出特徵
  • 深度架構：多層非線性、殘差連接、正規化技巧
  • 訓練技巧：學習率排程、Dropout、BatchNorm

L11302｜模型選型與取捨

  • 資料量與質量、特徵難度、可解釋性需求、時延/資源限制
  • 基準線（Baseline）→ 漸進提升 → 風險對齊

L114 鑑別式 AI 與生成式 AI 概念

目標：理解差異、優勢與實務整合

  • L11401 基本原理
  • L11402 整合應用

L11401｜鑑別式 vs 生成式：定義

  • 鑑別式：直接學 P(y|x) 或決策邊界，擅長分類/預測
  • 生成式：學 P(x) 或 P(x,y)，可用於生成、缺失補全、資料增強
  • 直觀比喻：鑑別式像『門神』，生成式像『作家/模擬器』

L11401｜典型架構與任務

  • 鑑別式：Logistic、SVM、樹模型、判別式 Transformer（分類/檢索）
  • 生成式：VAE、GAN、擴散模型、語言模型（LLM）、多模態模型

L11401｜Transformers 與 LLM 概念

  • 自注意力機制：擅長長距依賴與並行計算
  • 預訓練 + 微調/指令對齊：通才能力 + 任務化
  • 能力與限制：幻覺、可控性、資料/計算消耗

L11402｜整合應用範式

  • 檢索增強生成（RAG）：以檢索（多為鑑別式）支援生成回答
  • 生成 → 鑑別：由鑑別式檢核品質/安全/分類
  • 鑑別 → 生成：先分類意圖/語境，再以生成式回應

L11402｜案例：客服與知識助理

  • 意圖分類（鑑別式）→ 文件檢索（鑑別式）→ 草稿生成（生成式）→ 人工審校
  • 監控：回覆品質、延遲、錯誤率、升級至人工比例

L11402｜案例：內容創作與審核

  • 主題抽取/相似度過濾（鑑別式）→ 文本/圖像/影片生成（生成式）→ 合規審核（鑑別式）
  • A/B 測試與多臂賭徒策略優化

L11402｜風險與對策（生成式）

  • 事實幻覺與偏見 → 檢索增強、限制領域、人工審核
  • 濫用與安全 → 內容過濾、使用者驗證、速率限制與水印
  • 版權與資料來源 → 授權管理、引用/追溯、資料最小化

常見迷思澄清

  • 迷思：資料多一定比較好 → 需重質不重量並關注分佈
  • 迷思：深度學習不可解釋 → 有局部解釋工具與因果分析輔助
  • 迷思：生成式可取代所有任務 → 與檢索/鑑別式互補更務實

  • 提示工程（Prompting）、RAG、微調（Fine-tuning）

附錄｜資料前處理範例（Pseudo-code）


# 假設有一份帶標籤的表格資料 df
# 1) 清理
df = drop_duplicates(df)
df = impute_missing(df, strategy="median")
# 2) 轉換
df = standardize_numeric(df, cols=["age","income"])
df = one_hot_encode(df, cols=["city","channel"])
# 3) 切分
train, valid, test = split(df, ratios=(0.7,0.15,0.15), stratify="label")
# 4) 建模（樹模型）
model = GradientBoosting().fit(train.X, train.y)
# 5) 評估
report = evaluate(model, valid.X, valid.y, metrics=["AUC","F1"])
# 6) 部署前檢查：漂移監測、資安掃描、資料去識別化

附錄｜RAG 概念流程

  • Step1：解析使用者意圖與查詢改寫
  • Step2：檢索向量資料庫（鑑別式）
  • Step3：組裝提示與引用（Citation）
  • Step4：生成答案（生成式）+ 品質/安全檢核（鑑別式）

附錄｜常見錯誤與排除
