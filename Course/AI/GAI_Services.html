🤖 知名生成式 AI 服務應用一覽

應用 (Application) 服務名稱 (Service Name) 公司 (Company) 簡述 (Description)
問答
(Q&A/Chatbot)		 ChatGPT OpenAI 基於大型語言模型 (LLM)，提供廣泛的問答、文本生成、摘要和翻譯功能。
Gemini (原名 Bard) Google Google 的生成式 AI，整合搜尋能力，可用於問答、創意生成、程式碼撰寫等。
Claude Anthropic 專注於安全性和實用性的對話式 AI，擅長處理長篇文本和複雜推理。
Text to Image
(文本轉圖像)		 Midjourney Midjourney 高品質藝術圖像生成工具，透過 Discord 介面操作，以其美學風格聞名。
DALL-E 3 OpenAI OpenAI 的圖像生成模型，擅長理解複雜且詳細的提示，並與 ChatGPT 深度整合。
Stable Diffusion Stability AI 開源的文本轉圖像模型，擁有龐大的社群和高度可定製性。
Text/Image to Video
(文本/圖像轉影片)		 Runway Gen-2 Runway 領先的 AI 影片生成平台，可從文本或圖像提示生成影片片段。
Pika Labs Pika Labs 另一個快速發展的 AI 影片生成工具，能生成高品質、風格多樣的動畫和影片。
OpenAI Sora OpenAI (尚未公開) OpenAI 的文本轉影片模型，以生成長且連貫的高品質影片著稱。
Speech to Text
(語音轉文字)		 Whisper OpenAI 開源的語音識別模型，可將語音檔案高準確度轉錄成文字，並支援多語言翻譯。
Google Cloud Speech-to-Text Google Google 的企業級語音轉文字服務，提供高準確度的語音識別和即時轉錄功能。
Text to Speech
(文本轉語音)		 ElevenLabs ElevenLabs 提供極為逼真和富有情感的語音合成服務，支持多種語言和語音克隆。
Google Cloud Text-to-Speech Google Google 的企業級語音合成服務，提供 WaveNet 和標準聲音選項。
Text to Music
(文本轉音樂)		 Suno AI Suno AI 能夠根據文本提示生成帶有人聲和歌詞的完整歌曲。
Google Lyria (MusicFX) Google Google 的實驗性音樂生成工具 (Lyria 模型)，可根據描述生成音樂片段。
Text to Code
(文本轉程式碼)		 GitHub Copilot GitHub (Microsoft) 整合到程式碼編輯器中的 AI 程式設計助手，能根據註釋和上下文自動完成和建議程式碼。
Amazon CodeWhisperer Amazon Amazon 推出的 AI 程式碼生成工具，專注於提高開發人員在 AWS 上的生產力。
Text to Presentation
(文本轉簡報)		 Tome Tome 一個 AI 驅動的故事敘述和簡報工具，可以快速將文本大綱或想法轉換為視覺化的簡報。
Gamma Gamma 使用 AI 快速生成美觀的簡報、文件和網頁，並提供多種設計模板。
Agent
(自主代理/工作流)		 Auto-GPT / BabyAGI(開源) 開源社群 實驗性的自主 AI 代理，能設定目標並自主生成、執行和調整計畫以達成該目標。
OpenAI Function/Tools OpenAI 雖然不是獨立服務，但其 LLM 能夠使用工具和函數來規劃和執行多步驟任務，是 Agent 應用的基礎。
Calendar
(行事曆/排程)		 Motion Motion AI 驅動的時間管理和行事曆應用，能自動安排任務和會議，優化每日行程。
Reclaim.ai Reclaim.ai 智能行事曆助理，自動在 Google Calendar 中為任務、習慣和休息時間預留時間。
